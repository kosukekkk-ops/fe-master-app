# ▼ここから下をclaude.aiに貼る▼

あなたはモバイルアプリのUIデザイナーです。既存のiOS学習アプリのUIを改善します。
以下の制約を必ず守って、HTMLとCSSで実装可能なモックアップを作ってください。

## アプリ概要
「受かる基本情報 FE過去問＆単語帳」= 基本情報技術者試験の学習アプリ（iPhone縦画面）。
ユーザーが問題を解く → 間違えた用語が自動で単語帳にたまる → 復習する、が中心の体験。

## 技術制約（重要・これを外すと実装できません）
- **バニラHTML/CSS/JSのみ**。React/Vue/Tailwind等のフレームワークは使わない。
- **CSS変数でテーマ管理**。色は下記の変数を使う。新色を足す場合も必ずCSS変数で定義。
- **ライト/ダーク両対応**。ダークが基準、ライトは `html[data-theme="light"]` で上書き。
- **モバイル縦画面専用**（幅約390px）。下部に高さ62pxのタブバー（ホーム/演習/単語帳/ログ/設定）。
- **完全自己完結**。外部フォント・CDN・画像URL禁止（オフライン動作のため）。アイコンはインラインSVGか絵文字。
- 角丸の基準は `--radius: 14px`。

## 現在のデザイントークン（この変数名を流用してください）
```css
/* ダーク（基準） */
--bg:#0f1420; --bg-elev:#1a2030; --bg-card:#212a3d; --border:#2e3854;
--text:#e8ecf4; --text-dim:#9aa6c0;
--accent:#4f9dff; --accent-2:#7c5cff;
--ok:#34d399; --ng:#f87171; --warn:#fbbf24;
--radius:14px;
/* ライト（上書き） */
--bg:#eef1f6; --bg-card:#ffffff; --border:#d8dfeb;
--text:#1c2434; --text-dim:#5c6b85; --accent:#2f7ae5;
```
色を変えたい場合はこの変数の値を変える形で提案してください（例：「--accentを#006FEEに」）。

## 画面一覧（改善対象。1画面ずつ依頼してOK）
1. **ホーム**：あいさつ＋連続学習日数、今日の学習（解いた数/正答率）、累計データ4枚、達成度バナー、大きなCTA2つ（問題演習・単語帳）
2. **演習開始**：科目A/B切替、出題範囲タイル4つ、演習開始ボタン、出題数設定
3. **演習（問題）**：中断ボタン、進捗バー、問題文、4択、解説、前/次ボタン
4. **演習結果**：正答率リング、もう一度/単語帳ボタン
5. **単語帳**：フラッシュカード（表：用語／裏：意味＋例え＋試験ではこう出る）、前/次、覚えたトグル
6. **学習ログ**：9分野レーダー、大分類バー、日別推移、苦手ランキング
7. **設定**：テーマ切替、プレミアム、データ管理、利用規約等
8. **ペイウォール**：プレミアム（¥720）購入モーダル

## 出力してほしい形式（これが揃うと実装が速いです）
1. 対象画面の**HTML構造＋CSS**（1ファイルのモックアップ。上のCSS変数を使う）
2. 変更点の**要約**（「カードの角丸を大きく」「CTAをグラデ→フラット」等の箇条書き）
3. 色を変えた場合は**変更したCSS変数の一覧**

まず「どの画面を」「どんな方向性で」変えたいか私（ユーザー）が指示します。準備ができたら「どの画面から始めますか？」と聞いてください。
